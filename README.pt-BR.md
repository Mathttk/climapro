
# ❄️ ClimaPro — Landing Page Responsiva

**Landing page moderna e responsiva desenvolvida para uma empresa fictícia de climatização.**

[🇺🇸 English](README.md) | 🇧🇷 **Português**

---

## 🌐 Demonstração Online

**[Acessar ClimaPro](https://mathttk.github.io/climapro/)**

O ClimaPro é um projeto web front-end desenvolvido para apresentar serviços de climatização por meio de um site moderno, acessível e responsivo.

O projeto prioriza uma identidade visual limpa, navegação intuitiva e captação de contatos pelo WhatsApp.


## 📸 Captura de Tela

![ClimaPro Website](assets/images/og-climapro.jpg)

## ✨ Funcionalidades

- Layout responsivo para computadores e celulares
- Interface moderna e organizada
- Menu de navegação para dispositivos móveis
- Seções de apresentação dos serviços
- Formulário de contato e orçamento
- Integração com WhatsApp
- Validação do formulário utilizando JavaScript
- Recursos de acessibilidade, incluindo link para pular a navegação

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Design responsivo
- HTML semântico

## 📱 Design Responsivo

O site se adapta a diferentes tamanhos de tela, oferecendo uma experiência consistente em computadores, tablets e smartphones.

## 🚀 Como Executar

1. Baixe ou clone este repositório.
2. Abra `index.html` em um navegador moderno.
3. Explore o site e suas funcionalidades interativas.

Não é necessário instalar dependências ou configurar um backend.

## 📌 Objetivo do Projeto

O ClimaPro foi desenvolvido para o portfólio, demonstrando habilidades em desenvolvimento front-end, responsividade, acessibilidade e interfaces interativas.

**Observação:** o ClimaPro representa uma empresa fictícia. O formulário de orçamento é uma demonstração front-end e não envia informações para um servidor.

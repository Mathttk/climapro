
# ❄️ ClimaPro — Responsive HVAC Landing Page

**A modern, responsive landing page developed for a fictional air conditioning and climate control company.**

## 🌐 Live Demo

**[Visit ClimaPro](https://mathttk.github.io/climapro/)**

ClimaPro is a front-end web project designed to present HVAC services through a modern, accessible, and responsive website.

The project focuses on clean design, intuitive navigation, and lead generation through WhatsApp.


## 📸 Screenshot

![ClimaPro Website](assets/images/og-climapro.jpg)

## ✨ Features

- Responsive layout for desktop and mobile devices
- Modern and clean visual design
- Mobile navigation menu
- Service presentation sections
- Contact and quotation form
- WhatsApp integration for quotation requests
- Form validation using JavaScript
- Accessibility features, including skip navigation

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Semantic HTML

## 📱 Responsive Design

The website adapts to different screen sizes, providing a consistent experience across desktop computers, tablets, and smartphones.

## 🚀 Getting Started

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Explore the website and its interactive features.

No backend or installation is required.

## 📌 Project Purpose

ClimaPro was developed as a portfolio project to demonstrate front-end development skills, responsive layouts, accessibility practices, and interactive user interfaces.

**Note:** ClimaPro is a fictional company created for demonstration purposes. The WhatsApp quotation form is a front-end demonstration and does not submit information to a backend.
